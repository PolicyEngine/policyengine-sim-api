The v2 Modal coordinator now uses the stored output file of a report run's baseline or reform simulation run that already succeeded, instead of calculating that simulation again. It reads the file from whichever Cloud Storage bucket the run's `output_uri` names and checks its SHA-256 digest, year, versions, planned outputs and SPM calculation receipt. A file it can't use fails the report run with a `reused_simulation_output_missing`, `reused_simulation_output_unreadable`, `reused_simulation_output_digest_mismatch`, `reused_simulation_output_incompatible` or `reused_simulation_run_mismatch` error, and the reused simulation run is never written to.

Added `calculate_household_us` and `calculate_household_uk` to the v2 Modal application. Each calculates one household, with optional axes, under one to ten policies in a single call, the way the Public API calculates households, in an image without datasets. Given a household job's ID, a function claims that job under its Modal call ID and records its result, or its failure document with a one-line summary, as the Modal worker role, whose database secret is the functions' only secret; a call that names no job touches no database. The stuck-run sweep also fails household jobs nothing will finish. Version manifest schema version 2 records each country's capabilities, and the Simulation Entrypoint's comparison runs accept only economy-capable countries.

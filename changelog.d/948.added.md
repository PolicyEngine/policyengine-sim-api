Added the result tables, in migration revision `0004` of the `simulation` schema. Each section of an economy result (`SingleYearMacroOutput`) is stored as rows: a simulation run's poverty rates, inequality and cliff impacts, and a report run's budget, program, decile, intra-decile, labour supply, congressional district, constituency and local authority impacts. A computed household is stored as one JSON value on its simulation run, and `output_files` links each stored file to one run. A reader rebuilds the economy result exactly from the rows, with constituency and local authority names and map positions from the region catalog. No route writes results yet.

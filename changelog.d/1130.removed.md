Versioned simulation apps deployed from this release define their workers only as the `SimulationWorker` and `SimulationSegmentWorker` classes. The plain `run_simulation` and `run_simulation_segment` functions, which served callers still running the code from before the classes, are removed.

The gateway now spawns annual simulations only through the `SimulationWorker` class, and no longer falls back to the plain `run_simulation` function of apps deployed before the classes. A request routed to one of those apps (every policyengine.py release before 6.20.0), whether pinned or after a rollback of `latest`, now fails instead of running there.

Every Simulation Entrypoint deploy now mounts sim's own Modal token as `MODAL_TOKEN_ID` and `MODAL_TOKEN_SECRET`, no longer only when `DEPLOY_STAGE12_V2` is `true`.

Every deploy now also needs, in both `beta` and `prod`, the `MODAL_TOKEN_ID_SECRET_NAME` and `MODAL_TOKEN_SECRET_SECRET_NAME` environment variables naming sim's own Modal token secrets, the `MODAL_WORKSPACE_ID` environment variable, and the `SIMULATION_SAFETY_CHECK_SCHEDULER_SERVICE_ACCOUNT` environment variable with a scheduler service account allowed to run the safety-check job. Without the first three the entrypoint deploy stops; without the last, the promotion's safety-check step fails and traffic goes back to the previous revision.

The Simulation Entrypoint's log records now carry their fields. 31 of its 33 log calls passed their fields only as standard-library `extra=` keys, which the observability runtime doesn't emit, so their records in Cloud Logging named no job, report, run or error type. Every log call now passes its fields through `log_extra` in the shared observability library, and names a Public API row with `database_table` (`household_jobs`, `reports`, `report_runs` or `simulations`) and `database_row_id`: a key such as `household_job_id` would be dropped by the runtime's key filter. A budget window's `started_years` are now joined into one string, since the runtime drops lists.

The rule `sim.persistence.orm-only` requires database code to declare tables as SQLAlchemy ORM mapped classes and to run every statement through an ORM Session. It starts ratcheted: `rules/baselines/orm-only.txt` lists the Core code the persistence libraries have today, a new finding fails CI, and issue #1097 tracks the conversion. The unused `policyengine_fastapi.database` module is removed.

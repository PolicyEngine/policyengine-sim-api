The v2 app's US workers, `SimulationSegmentWorkerUS` and `SimulationWorkerUS`, now run one warm-up calculation before Modal takes their memory snapshot, so a container restored from the snapshot starts with the year's parameter values built. The warm-up calculates the reform side of the first region group the v2 cache precomputes (Hawaii, Iowa and Wisconsin) for 2026, under a raised Child Tax Credit base amount, only in a container Modal takes a snapshot from. It reads no Modal Secret, opens no connection, sends no telemetry, doesn't count as a worker call and leaves nothing for later calls; a failure only logs a warning. Containers that take a snapshot start later by about one segment's calculation. The UK worker doesn't warm up yet.

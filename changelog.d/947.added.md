Added simulation runs and report runs, in migration revision `0003` of the `simulation` schema. Each run has its own status and Modal call, every status change is one conditional update, and only the instance that claims a run starts its Modal call. When a v2 Modal call ends, the new `report_call_ended` Modal function reports it on `POST /internal/modal-calls/ended`, which accepts only a Modal identity token from that function; sim then reads the call's outcome from Modal and records it on the runs. A new Cloud Run job, `<service>-safety-check`, runs every five minutes on Cloud Scheduler and records calls that ended without a report. No route creates runs yet.

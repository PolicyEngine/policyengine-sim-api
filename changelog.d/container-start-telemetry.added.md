Each `run_simulation`, `run_simulation_segment` and `run_budget_window_batch` call's operation log record and span now carry `container_start` (`restored_from_snapshot`, `took_snapshot` or `no_snapshot`) and `container_call_number`, the call's number in its container, so Cloud Logging and Cloud Trace show which calls ran in containers restored from a memory snapshot and how long those containers took to set up.

Segment children of segmented national runs (the `SimulationSegmentWorker` class and the plain `run_simulation_segment` function) now request 1 CPU and 6 GiB instead of 8 CPUs and 32 GiB. A child calculates one region group (a set of states) in one process, so it uses one CPU and about 3 to 3.4 GiB, and the 20 children of a segmented national run cost about a sixth as much at list price.

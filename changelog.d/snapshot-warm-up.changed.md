The simulation workers' snapshot hook now runs one warm-up calculation of a region group baked into the image, for the first precompute year, in each container Modal takes a memory snapshot from. Containers restored from the snapshot then start with that year's US parameter values and SPM amounts built, which made their first calculation 11 to 15 s faster on Modal `testing`. Containers that take a snapshot start about 70 to 100 s later. A warm-up that fails or can't run safely only logs a warning, and the container starts as before.

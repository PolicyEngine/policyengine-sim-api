A Modal preemption of a simulation worker, segment worker or Stage 12 function is now recorded as an interrupted operation at WARNING instead of a failed one at ERROR, so it no longer opens telemetry error issues. Modal delivers a preemption as `KeyboardInterrupt` and runs the same input again; the executor, the gateway and the entrypoint now require policyengine-observability 3.0.7, which records an operation, request or span that ends in `KeyboardInterrupt` with the outcome `interrupted` and leaves it out of the error count metric. The move from 3.0.4 also brings 3.0.5's change: a record written while a FastAPI endpoint runs, such as `exception.recorded`, carries the matched route template as `http.route` instead of `<unmatched>`.

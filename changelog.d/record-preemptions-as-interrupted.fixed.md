A Modal preemption of a simulation worker, segment worker or Stage 12 function is now recorded as an interrupted operation at WARNING instead of a failed one at ERROR, so it no longer opens telemetry error issues. Modal delivers a preemption as `KeyboardInterrupt` and runs the same input again; the simulation executor now uses a policyengine-observability release that records an operation ending in `KeyboardInterrupt` with the outcome `interrupted`.
